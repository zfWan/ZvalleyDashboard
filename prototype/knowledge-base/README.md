# 知识库系统 · 可交互高保真原型

ZValleyDashboard「知识库系统」原型阶段交付物（可交互 HTML 高保真原型，非生产实现）。

## 打开方式

直接使用主流浏览器（Chrome / Edge / Safari）打开本目录下的 `index.html` 即可，无需启动服务、无需安装依赖。

## 覆盖范围

依据《docs/requirements/知识库系统-Spec.md》评审建议默认值实现：

| 能力 | 说明 |
| --- | --- |
| 主流程 A：创建文档 | 新建文档（空白 / 模板）→ 填写标题、正文、标签、分类 → 保存 → 出现在列表并可检索 |
| 主流程 B：检索与浏览 | 关键词匹配标题 / 正文 / 标签（不区分大小写，提交式检索），支持分类 / 标签筛选与清除筛选 |
| 主流程 C：模板复用 | 预置 3 个模板（技术方案 / PRD / 测试用例），选择后预填充编辑器 |
| 文档查看与编辑 | 详情页 Markdown 渲染（含预览）、编辑保存、删除（二次确认） |
| 分类与标签 | 一级分类 + 默认分类「未分类」，支持新建分类；标签增删（≤20 字符 / 个，≤10 个 / 文档） |
| 状态与反馈 | 保存成功 / 失败可重试且输入不丢失、空态、无搜索结果、加载中、加载失败可重试 |

## 评审演示建议

页面右下角「原型演示控制台」可一键演示异常与边界状态（**演示用，非产品功能**）：

- **模拟列表加载失败**：进入首页 / 详情时展示错误态与「重试」。
- **模拟保存失败**：编辑页保存时展示失败提示，输入内容保留，可重试。
- **模拟空数据**：首页展示「暂无文档」空态与新建引导。

## 范围边界（Non-Goal）

- 不做多租户与权限体系（导航中其余入口仅为示意，点击会提示）。
- 无生产后端 / 数据库 / 鉴权：数据为内存模拟，刷新后恢复预置种子数据。
- 不做审计与统计、版本管理与回收站、多级目录树。

## 目录结构

```
prototype/knowledge-base/
├── index.html          # 页面骨架与主导航
├── css/style.css       # 样式（通用 Dashboard 风格）
└── js/
    ├── data.js         # 模拟数据：种子文档 / 分类 / 模板
    └── app.js          # 视图渲染、路由、检索、交互
```
